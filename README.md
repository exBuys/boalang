--- BoaLang ---
BoaLang is a beginner-friendly programming language written in Python.
The goal of BoaLang is to make programming syntax simple and easy to understand.
Example:
  name = ask "What's your name? "

say "Hello!"
say name

--- Current Features ---
say - print text
ask - get user input
Variables
Integers
Floats
Arithmetic operators
Assignment operators
Comparison operators
if
else
repeat

--- Example: Variables ---
name = "Isaiah"
age = 18

say name
say age

--- Example: If Statements ---
age = 18

if age >= 18:
    say "You are an adult."
else:
    say "You are under 18."
    
--- Example: Repeat ---
repeat 3:
    say "Hello!"
    
--- Operators --- 
BoaLang currently supports:
+    -    *    /    %    **    //
+=   -=   *=   /=   %=   **=   //=
==   !=   >    <    >=   <=

--- Status ---
BoaLang is currently in development.
More features will be added over time.
